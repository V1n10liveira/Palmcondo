# Palmcondo

Sistema de controle de acesso para condomínios residenciais.

## Objetivo

O Palmcondo tem como objetivo proporcionar maior segurança, organização e praticidade no controle de acesso de moradores, visitantes, prestadores de serviços e funcionários.

- JavaScript
